Installing

./install.sh --global
./install.sh --skill ticket-demo-video --global

Copies skills into Grok, Claude, and Cursor. Start a new session after install. ticket-demo-video and claim-fix-ticket pull playwright-agent automatically. install.sh does not enable the Claude Remote Control unit — that is the next section.

Claude Remote Control setup

Copying the skill is not the same as leaving claude remote-control running as a service.

Local box (this laptop)

Puts /claude-rc-setup into your agent homes. On macOS or Windows the probe stops at no-systemd — that is expected. Do not enable a unit here unless PID 1 is systemd. 

./install.sh --skill claude-rc-setup --global

curl -fsSL https://raw.githubusercontent.com/Yuri-Lima/skill-set/main/install.sh \
  | bash -s -- --skill claude-rc-setup --global

Remote box (Linux host you will attach to)

SSH as the same user that already ran claude /login. Need systemd, the claude CLI, ~/.claude, and sudo.

  1. Install the playbook with the same curl line as above.
  2. In a project directory (not $HOME, not /), accept first-run prompts — a unit cannot: 
    cd /path/to/project
claude
claude remote-control --name UNIQUE-HOST --spawn same-dir
# wait for the session URL / QR, then Ctrl-C
  3. New Claude Code session in that directory: /claude-rc-setup. Confirm WORKDIR, NAME, and the login user.
  4. Open claude.ai/code or the phone app. Computer icon, green dot.

Day to day: sudo systemctl status claude-rc. Remove with /claude-rc-setup and ask for undo.

Playwright agent

You name the control (“Sign in”, “Email”). Playwright finds it. If it cannot find exactly one match, it stops. Full guide: playwright-agent/README.md.

Evals and demo videos

Evals grade decisions, not live video. Demo mp4s stay local — upload them onto the merge request. Do not commit them.

Job-wired skills assume this author’s GitLab boards, Phoenix-style locators, demo-auth.json, and Eve assets. Swap those hosts, login, and locators before you run them on another repo.
